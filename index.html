todevelopers Flatpaks

Self-hosted Flatpak remote for applications by todevelopers.

Add the remote

One-time setup:

flatpak remote-add --if-not-exists --no-gpg-verify todevelopers \
    https://todevelopers.github.io/flatpaks/todevelopers.flatpakrepo

Applications

GSE Profiler

GTK4 desktop application for managing, debugging, and profiling GNOME Shell extensions.

Source on GitHub

stable (recommended):

flatpak install todevelopers io.github.todevelopers.GseProfiler

Or click: io.github.todevelopers.GseProfiler.flatpakref

testing (latest prerelease):

flatpak install todevelopers io.github.todevelopers.GseProfiler//testing

Or click: io.github.todevelopers.GseProfiler-testing.flatpakref

Updates

flatpak update
