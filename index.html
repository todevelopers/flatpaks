todevelopers Flatpaks

Self-hosted Flatpak remotes for applications by todevelopers.

Add a remote

Pick one or both. Stable is recommended for most users.

Stable channel — production-ready releases: 
flatpak remote-add --if-not-exists todevelopers \
    https://todevelopers.github.io/flatpaks/todevelopers.flatpakrepo
Testing channel — prerelease builds (rc, beta) for early testing: 
flatpak remote-add --if-not-exists todevelopers-testing \
    https://todevelopers.github.io/flatpaks/todevelopers-testing.flatpakrepo

Applications

GSE Profiler

GTK4 desktop application for managing, debugging, and profiling GNOME Shell extensions.

Source on GitHub

Install stable:

flatpak install todevelopers io.github.todevelopers.GseProfiler

or click: io.github.todevelopers.GseProfiler.flatpakref

Install testing:

flatpak install todevelopers-testing io.github.todevelopers.GseProfiler

or click: io.github.todevelopers.GseProfiler-testing.flatpakref
